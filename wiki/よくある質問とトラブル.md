# よくある質問とトラブル

症状から探してください。解決しないときは、受信アプリの左メニュー **「状態」** の内容を添えて [Issues](https://github.com/syuuga101/phonecam/issues) へ。

## 接続できない

| 症状 | 対処 |
|---|---|
| 「Apple Mobile Device Service に接続できません」 | iTunes（Apple 公式サイト版）、または Microsoft Store の「Apple Devices」アプリを入れて、PC を再起動します。 |
| 「iPhoneがUSBで見つかりません」 | ケーブルを確認し、iPhone のロックを解除して「このコンピュータを信頼」を押します。 |
| 「iPhoneのPhoneCamアプリに接続できません」 | iPhone で PhoneCam を起動し、**前面に表示したまま**にします。 |
| Wi-Fi で接続できない | Wi-Fi は初期状態でオフです。iPhone アプリ右上の歯車（設定）で「Wi-Fiからの接続を許可」をオンにしてください。iPhone と PC が同じネットワークか確認し、初回のローカルネットワークの許可も必要です。 |
| 「ペアリングコードが違います」 | iPhone の画面に表示されている 6 桁のコードを入力してください（「コードを変更」で変えた場合は新しいコード）。同じ PC から 3 回続けて間違えると、60 秒は受け付けません。 |
| 画面が消えて止まる | iPhone をロックするとカメラが止まります。アプリを前面に表示したままにしてください。 |

## iPhone にアプリが入らない・更新できない（SideStore）

iPhone のアプリは SideStore で入れて、更新します（[[iPhoneアプリの入れ方（SideStore）]]、[[アップデート方法]]）。更新の前に、まず次の 3 つを確かめてください。これだけで直ることが多いです。

1. **LocalDevVPN** が **Connect** になっている（画面の上に VPN のマークが出ています）
2. iPhone が **Wi-Fi** につながっている（モバイル回線では更新できません）
3. VPN をほかに使っている（WireGuard など）ときは、オフにして、DNS ブロッカー（広告ブロックなど）もオフにする

### 数日後にアプリが開かなくなった

無料の Apple ID は **7 日で期限切れ**になります。LocalDevVPN を Connect、Wi-Fi につないで、SideStore の **My Apps** で、アプリの右の **7 DAYS** を押して更新します。SideStore 自身が切れているときは、先に SideStore を更新します。手順は [[アップデート方法]] の「7 日ごとの更新」。

### 更新できない（「AFC Connection Failure」「No Wi-Fi or VPN Connection」など）

SideStore が、iPhone の中の通信（minimuxer）につながっていない状態です。次を、1 つずつ試して、そのたびに更新してみてください。

1. WireGuard や StosVPN を使っているなら、**LocalDevVPN** に切り替える
2. DNS ブロッカーをオフにする
3. LocalDevVPN と Wi-Fi の **両方につながっている** ことを確かめる
4. もう一度押す（何回か押すと通ることがあります）
5. SideStore を終了して、開き直す
6. LocalDevVPN を切って、もう一度 **Connect** する
7. それでもだめなら、ペアリングファイルを入れ直す（次の項目）

### ペアリングファイルの期限切れ

**ペアリングファイル**は、iPhone と PC が「お互いを知っている」という印のファイルで、SideStore はこれを使って iPhone と通信します。**iOS を更新したとき、iPhone を初期化したとき**などに、使えなくなることがあります（Apple の仕組みで、SideStore 側では防げません）。更新できなくなったら、PC の **iloader** で入れ直します。

1. iPhone を USB で PC につなぎ、ロックを解除します。
2. PC で **iloader** を開き、iloader から更新を求められたら、更新します。
3. **Delete Stored Pairing** を押して、古いペアリングファイルを消します。
4. 一覧から自分の iPhone を選び、iPhone に出る確認で **信頼**（Trust）を押します。
5. iloader に戻り、**Manage Pairing File** を押します。
6. **SideStore**（と、必要なほかのアプリ）の横の **Place** を押します。緑色で **Pairing file placed successfully!** と出たら完了です。

それでもだめなときは、iPhone と PC を再起動してから、もう一度やります。

### 「3 アプリまで」と出る・SideStore に入らない（3アプリ制限）

無料の Apple ID で、同時に有効にできるアプリは、**SideStore 自身を含めて 3 つまで**です。また、1 週間に入れられる「別々のアプリ」は **10 種類まで**です。

- 使っていないアプリを、SideStore の **My Apps** から消してください（または、ほかの Apple ID を使います）。
- AltStore から乗り換えた人は、AltStore が 1 つ数えられています。使わないなら消してください（[[iPhoneアプリの入れ方（SideStore）]] の「AltStore から乗り換える」）。
- 有料の Apple Developer アカウント（年 $99）なら、この制限はなくなります。

### 「デベロッパモード」が出ない

**設定 > プライバシーとセキュリティ** のいちばん下に「デベロッパモード」（Developer Mode）が出るのは、**SideStore などを iloader で入れたあと**です。

1. まず、手順 2 の **Install SideStore (Stable)** が終わっているか確認します。
2. 設定 > プライバシーとセキュリティ を、**いちばん下までスクロール**します。
3. それでも出ないときは、iPhone を再起動して、もう一度見ます。
4. 出たら、オンにして、iPhone の再起動を待ちます。

また、**設定 > 一般 > VPNとデバイス管理** で、自分の Apple ID を **信頼** していないと、SideStore が開きません。

### サインインできない・エラーが出る

SideStore や iloader で Apple ID にサインインできないときは、次を試します。

- **メールアドレスとパスワード** を確かめる（**大文字と小文字は区別されます**）。
- 2 ファクタ認証（確認コード）が出たら、iPhone に届いたコードを入力する。
- SideStore の **Settings** で、**Anisette URL**（サインインを手伝うサーバー）を変える。サーバーが一時的に止まっていると、サインインできないことがあります。
- 数分たってから、もう一度やる。
- SideStore のエラー番号は、[公式のエラーコード一覧](https://docs.sidestore.io/docs/troubleshooting/error-codes) で調べられます。

### モバイル回線では更新できない

SideStore の更新は、**Wi-Fi につながっている**ときにします（モバイル回線ではできません）。外出先で期限が切れたときは、Wi-Fi のある場所で、LocalDevVPN を Connect にして、更新してください。

### SideStore が開かない・途中で止まる

1. SideStore を、**iloader で入れ直す**（PC につなぎ、**Install SideStore (Stable)**）。入れ直したあとは、先に SideStore で更新してから、PhoneCam などを入れます。
2. それでもだめなときは、SideStore と、SideStore から入れたアプリをいったん消して、入れ直します。

そのほかは、[SideStore 公式のトラブルシューティング](https://docs.sidestore.io/docs/troubleshooting/common-issues) と [FAQ](https://docs.sidestore.io/docs/faq) へ。

### 「requires additional permissions not specified by the source」と出る

PhoneCam v1.3.5 以降で直っています。SideStore の **Sources** で、PhoneCam のソースを入れ直して、最新版を入手してください。

詳しくは [[iPhoneアプリの入れ方（SideStore）]]。

## セットアップ（必要なソフトのインストール）

| 症状 | 対処 |
|---|---|
| iTunes・VB-CABLE のインストールがうまくいかない | これらは **公式のインストーラーが画面に開きます**。画面の手順（「インストーラーを開く」→ 案内どおりに押す →「確認」）に沿って進めてください。インストーラーの画面が見えないときは、ほかのウィンドウの後ろやタスクバーを確認してください（3 分たつと画面にも案内が出ます）。 |
| 「確認」を押しても「まだ見つかりません」と出る | インストーラーを最後の「完了」まで進めましたか？ 再起動が必要と出たときは、PC を再起動してから、設定の「初期セットアップ」を開き、「再チェック」を押します。 |
| 「公式ページを開く」 | 受信アプリ経由でうまくいかないときは、公式ページから自分でダウンロードして実行し、設定の「初期セットアップ」を開き、「再チェック」を押してください。 |
| 管理者の確認（青い画面）で「いいえ」を押した | もう一度「インストーラーを開く」を押して、「はい」を選びます。 |

## カメラが出ない・映像が出ない

| 症状 | 対処 |
|---|---|
| 「PhoneCam」がカメラ一覧に出ない／「未登録」と出る | 受信アプリを起動してください。左メニュー「映像」の「仮想カメラ」にある **登録する（更新）** を押します（管理者の確認で「はい」）。 |
| OBS で映像が出ない | 受信アプリで接続して映像が流れている必要があります。OBS のソースを開き直してください。 |
| Discord が黒い／カメラが動き始めない | 受信アプリを先に起動してから、Discord でカメラを選びます。サイズなどを変えたあとは、カメラを一度オフ→オン。左メニュー「状態」の「使用中の検出」が「未使用」ならカメラを選び直し、「共有メモリなし」ならカメラの登録と出力先を確認します。 |
| OBS Virtual Camera を開始できない | OBS Studio 30 以上を入れて、OBS 側の「仮想カメラ開始」がオンなら止めてください。 |
| 4K にすると映像が出ない／重い | 4K で送っても、仮想カメラは「出力サイズ」（既定 1920×1080）のままなのでそのまま使えます。CPU 負荷が高いときは「ハードウェアデコード」をオンにします（既定でオン）。 |

## 映像の品質

| 症状 | 対処 |
|---|---|
| 映像が固まる／乱れる | 自動でキーフレームを再要求します。直らないときは、ビットレートを下げるか、USB を使います。Wi-Fi のときは HEVC も試してください。 |
| 映像が暗い／ちらつく | 露出をマニュアルにして、シャッター速度を地域に合わせます（[[画質と遅延の調整]]）。 |

## 「PCの処理が追いつかないためフレームを間引いています」と出る（コマ落ち）

PC のデコードが映像に追いついていません。遅れを溜めないために、次のキーフレームまで映像を間引いています。次のことを試してください。

- **ハードウェアデコード** をオンにする（「映像」ページ）
- 出力サイズ（1080p など）を小さくする
- fps を下げる
- 4K で送っているなら 1080p にする

## 音声のトラブル

### VB-CABLE を入れたら PC の音が出なくなった

VB-CABLE のインストーラーが、Windows の「既定の音の出力先」を **CABLE** に切り替えてしまうことがあります。PhoneCam は自動で元に戻しますが（入れたあとの約 20 秒間と、次の 2 回の起動時）、戻らなかったときは、タスクバーのスピーカーのアイコンから出力先を元のスピーカー／ヘッドホンに選び直してください。

### iPhone のマイクの音が出ない・遅れる・途切れる

[[音声（iPhoneのマイク）を使う]] を見てください。

## アプリの動作

### 自動起動しない（カメラが使われても動き始めない）

カメラは初期設定の「**使われているときだけ（自動）**」のとき、OBS や Discord が PhoneCam を開いたときに動き始めます（判定に最大 3 秒、起動に 1〜2 秒）。

- 自動判定は、出力先が **PhoneCam（専用カメラ）** のときだけ使えます。
- 受信アプリを先に起動してください。
- 左メニュー「状態」の「使用中の検出」を確認してください。
- 自動のとき、**一時停止** を押すと止まります。OBS や Discord がカメラを開き直すか、**開始** を押すと再開します。
- 常に動かしたいときは、「接続中ずっと」にします。

### 画面の文字や行が切れる（高DPI）

受信アプリは高 DPI に対応しています。ウィザードは大きさを変えられ、中身はスクロールできます。それでも切れるときは、ウィンドウを広げてください。

## 質問

**Q. Mac は必要ですか？** いいえ。iPhone アプリも GitHub Actions で作っていて、SideStore で入れます。

**Q. Wi-Fi でも使えますか？** 使えます。ただし初期状態ではオフで、使うときは iPhone アプリで許可して、6 桁のペアリングコードを入力します。Wi-Fi の通信は暗号化されないので、信頼できるネットワークだけで使ってください。USB のほうが安定していて、遅延も小さいです。

**Q. 設定はどこに保存されますか？** `%APPDATA%\PhoneCam\phonecam_settings.json` です。

## それでも解決しないとき

[Issues](https://github.com/syuuga101/phonecam/issues) の「不具合の報告」から、環境（Windows / iPhone / PhoneCam のバージョン / USB か Wi-Fi か）と、左メニュー「状態」の内容を書いて送ってください。
