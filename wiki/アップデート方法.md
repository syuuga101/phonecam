# アップデート方法

新しいバージョンが出たら、**Windows の受信アプリ** と **iPhone のアプリ** の両方を更新します。変更内容は、[Releases](https://github.com/syuuga101/phonecam/releases) と [変更履歴](https://github.com/syuuga101/phonecam/blob/main/CHANGELOG.md) に書いてあります。

## Windows（受信アプリ）

受信アプリは、**アプリの中から自動で更新**できます。起動すると新しいバージョンを確認して、あると **「新しいバージョン vX.Y.Z があります」** と出ます。**今すぐ更新** を押すと、ダウンロードして入れ替え、アプリが再起動します（そのとき、接続中の映像はいったん切れます）。左メニュー「設定」の **更新を確認** からも確認できます。

自動で更新できないときは、手動でも更新できます。

1. [Releases](https://github.com/syuuga101/phonecam/releases/latest) から、最新の **PhoneCamReceiver.exe** をダウンロードします。
2. 受信アプリを終了して、古い exe を新しい exe に **置き換える** だけです（設定はそのまま引き継がれます）。

専用カメラの更新が必要なときは、起動時に案内が出ます。左メニュー「映像」の「仮想カメラ」にある **登録する（更新）** を押してください（管理者の確認で「はい」）。

## iPhone（アプリ）

iPhone は、**SideStore で更新**します。PC は要りません。

### PhoneCam を新しいバージョンにする

1. iPhone の **LocalDevVPN** を開いて、**Connect** を押します。
2. iPhone を **Wi-Fi** につなぎます（モバイル回線ではできません）。
3. **SideStore** を開きます。
4. 下のタブの **My Apps**（または **Sources** にある PhoneCam）に更新が出ていたら、**UPDATE** を押します。
5. 出ないときは、画面を下に引いて、更新を確認します。

ソースの URL（追加していないとき。[[iPhoneアプリの入れ方（SideStore）]] の手順 7）:

```
https://github.com/syuuga101/phonecam/releases/latest/download/altstore-source.json
```

### 7 日ごとの更新（期限を延ばす）

無料の Apple ID では、アプリは **7 日で期限が切れます**。期限が切れると、PhoneCam が開かなくなります。SideStore は、期限が近づくと、iPhone の中で自動で更新しようとします。ただし、**自動で動くのを待てないとき**や、うまくいかなかったときは、自分で更新します。

1. **LocalDevVPN** を開いて **Connect** を押します。
2. iPhone を **Wi-Fi** につなぎます。
3. **SideStore** を開き、**My Apps** を開きます。
4. アプリの右に **7 DAYS**（あと何日、という表示）が出ています。それを押すと、そのアプリが更新されます。
5. 「署名証明書を失効させるか、新しく作るか」という確認が出たら、**Yes** または **Refresh Now** を押します。

> **SideStore 自身**も 7 日で期限が切れます。PhoneCam と同じように、**SideStore の右の 7 DAYS** を押して更新してください。SideStore が切れると、中のアプリを更新できなくなります。
>
> 週に 1 回、SideStore を開いて、期限を確かめるのがおすすめです。

更新できないときは、[[よくある質問とトラブル]] の「更新できない」を見てください。

## バージョンをそろえましょう

PC と iPhone のバージョンが違っても、基本的には動きます（古いほうに合わせて動きます）。ただし、新しい機能（Wi-Fi のペアリングコードなど）は、両方を新しくしたときに使えます。

困ったときは [[よくある質問とトラブル]] へ。
