# 音声（iPhoneのマイク）を使う

iPhone のマイクの音を PC に送り、OBS や Discord のマイクとして使えます。そのために、無料のソフト **VB-CABLE**（仮想の音声ケーブル）を使います。

## しくみ

iPhone のマイク → PhoneCam 受信アプリ → **CABLE Input**（出力）→ VB-CABLE → **CABLE Output**（入力）→ OBS / Discord

## 手順

1. **VB-CABLE を入れる**: セットアップウィザードで入れるか、https://vb-audio.com/Cable/ から入れます（zip を展開して `VBCABLE_Setup_x64.exe` を管理者として実行）。**PC を再起動**します。
   - 入れても、普段のスピーカーとマイクは変わりません（変わってしまったときは、PhoneCam が元に戻します）。
2. 受信アプリの左メニュー「**音声**」で **iPhoneのマイクを使う** をオンにし、出力先を **CABLE Input** にします（CABLE Input があれば最初から選ばれます）。初めて使うときは、iPhone でマイクの許可が必要です。
3. **OBS**: **ソース追加 > 音声入力キャプチャ** で **CABLE Output** を選びます。
   **Discord など**: マイクに **CABLE Output** を選びます。
4. 映像より音が早いときは、**音声の遅延** を増やして合わせます。音量は 0〜200%、ミュートとレベルメーターもあります。

> 受信アプリを起動したあとに VB-CABLE を入れたときは、受信アプリを再起動してください。
> 出力先に「CABLE Input」を選ぶと、自分のスピーカーからは鳴りません。確認したいときは OBS の「音声モニタリング」を使います。

## 遅延をもっと小さくする

### 1. 再生バッファを「低遅延優先」にする（既定）

「音声」ページの **再生バッファ** で選べます。

- **低遅延優先**（既定）: いちばん遅延が小さい
- **安定優先**: 音が途切れるときはこちら

**アンダーラン回数** が増え続ける場合は、設定が攻めすぎです。「安定優先」にするか、排他モードをオフにしてください。

### 2. OBS の設定

OBS で「CABLE Output」の **音声入力キャプチャ** のプロパティを開き、**デバイスのタイムスタンプを使用** をオフにすると、遅延が減ることがあります。「高度なオーディオプロパティ」の同期オフセットが 0 になっているかも確認してください。

### 3. VB-CABLE の Max Latency を下げる

VB-CABLE の中にも、大きめのバッファがあります（初期値だと 48kHz で 100ms 以上になることがあります）。

1. 受信アプリの「音声」ページで **VB-CABLEの遅延設定を開く** を押します（管理者の確認が出たら「はい」）。VB-CABLE のコントロールパネルが開きます。
2. **Latency** メニューを開き、**2048 smp**（サンプル）を選びます。初期値より小さい値ほど、遅延が小さくなります。
3. **PC を再起動** します（反映に必要なことがあります）。

音が途切れるようになったら、一段大きい値に戻してください。ボタンが押せないときは、VB-CABLE のコントロールパネルが見つかっていません（VB-CABLE が入っているか確認してください）。

### Pull loss とは

VB-CABLE のコントロールパネルに出る **Pull loss** は、CABLE Output を読み取る側（OBS など）が音を取りにきたときに、音が足りなかった回数です。数が増え続けているときは、音が途切れています。Max Latency を一段大きくしてください。

## 表示の見かた

- **音声経路**: 「専用（低遅延）」か「映像と共用」か。通常は専用です。古い iPhone アプリでは、自動で「映像と共用」になります。
- **音声の遅延（PCの出力まで）**: iPhone で録音してから、PC の再生バッファを出るまでの平均です。**VB-CABLE 内部の遅延は含みません**。
- **再生モード**: 排他モード / 共有モード（使えない場合は自動で共有モードになります）。

## 困ったとき

- VB-CABLE を入れたら PC の音が出なくなった → [[よくある質問とトラブル]]
- 音が出ない: 出力先が **CABLE Input**、OBS / Discord 側が **CABLE Output** になっているか確認してください。
