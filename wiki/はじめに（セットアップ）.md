# はじめに（セットアップ）

PC に受信アプリを入れて、OBS や Discord でカメラが使えるようになるまでの手順です。所要時間は 15〜30 分ほどです。

## 用意するもの

- iPhone（iOS 17 以上）と USB ケーブル
- Windows 10 / 11 の PC
- Apple ID（無料のものでOK。サブのアカウントでも構いません）。iPhone にアプリを入れるのに使います

## 手順

### 1. 受信アプリをダウンロード

[Releases](https://github.com/syuuga101/phonecam/releases/latest) から **PhoneCamReceiver.exe** をダウンロードします（ファイルはこの 1 つだけです）。置き場所はどこでも構いません。

### 2. 起動してセットアップウィザードに従う

`PhoneCamReceiver.exe` をダブルクリックします。

> Windows の青い警告（SmartScreen）が出たら、**詳細情報 → 実行** を選びます。PhoneCam の exe にはまだ署名がついていないためです。

初回は **セットアップウィザード** が開きます。**次へ** を押して進めます。

1. **ようこそ**: 内容の説明です。
2. **必要なソフトの確認**: 入っているものは自動で「スキップ」になり、足りないものだけにチェックが付きます。**インストール** を押します。
3. **インストール**: 次の 2 通りで進みます。
   - **自動で入れるもの**（Visual C++ ランタイム、PhoneCam カメラの登録）: 管理者の確認（UAC）が **1回** 出るので **「はい」** を押します。
   - **手順つきで入れるもの**（iTunes・VB-CABLE）: ダウンロードと確認のあと、画面に押すボタンの手順が出ます。**インストーラーを開く** を押すと、公式のインストーラーが普通のウィンドウで開きます。案内どおりに進め、終わったら **確認** を押します。見つからないときは何が足りないかが表示され、**公式ページを開く** から自分で入れることもできます。インストーラーの画面が見えないときは、ほかのウィンドウの後ろやタスクバーを確認してください。
4. **iPhoneの準備**: iPhone にアプリを入れる手順を案内します。詳しくは [[iPhoneアプリの入れ方（SideStore）]]（iPhone には **SideStore** で入れます。PC で使う **iloader** は、そのページの案内で入れます）。

ウィザードが入れるもの（足りないものだけ）:

| ソフト | 用途 | 必要か |
|---|---|---|
| PhoneCamカメラ | OBS や Discord に出る専用カメラ | 必須 |
| Visual C++ ランタイム | 専用カメラの動作に必要 | 必須 |
| Apple USBドライバ（iTunes） | USB 接続に必要 | USB で使うなら必須 |
| VB-CABLE | iPhone のマイクを OBS などで使う | 任意（[[音声（iPhoneのマイク）を使う]]） |

- iTunes・VB-CABLE などを入れたあと、**PC の再起動が必要**になることがあります。インストーラーに「再起動」と出たら「あとで」を選び、セットアップがすべて終わってから再起動してください。
- 自動で入れられなかったものは、公式ページを開いて手順を案内します。エラーの表示には、次にやることが 1 行で書いてあります（技術的な内容は「詳細」に出ます）。
- あとから、左メニュー「**設定**」の **初期セットアップ**（「開く」）で、いつでも確認・インストールができます。

### 3. カメラを選ぶ

iPhone で PhoneCam アプリを開き、USB でつないだまま、受信アプリで接続します。映像が流れたら、OBS や Discord のカメラで **「PhoneCam」** を選びます。

- [[OBSで使う]]
- [[Discordで使う]]

## 画面の見かた（v2.0 以降）

**Windows（受信アプリ）**: 左のメニューから、各ページを開きます。

| メニュー | できること |
|---|---|
| 接続 | 接続の状態、受信映像のプレビュー（右下のつまみで大きさを変えられます）、接続方法、iPhone のカメラの動作 |
| 映像 | 解像度・fps・コーデック、向き、出力先と出力サイズ、PhoneCam カメラの登録、省電力 |
| 画質 | 露出・ホワイトバランス・フォーカス・ズーム・ライト |
| エフェクト | 背景（ぼかし・切り抜き）、色調整 |
| 音声 | iPhone のマイク（VB-CABLE への出力） |
| 録画 | iPhone 内での高画質録画 |
| 状態 | 遅延・温度・使用中の検出などの確認 |
| ショートカット | ショートカットキーの設定 |
| 設定 | 言語・外観（ライト／ダーク）・更新・初期セットアップ・アプリについて |

**iPhone（PhoneCam アプリ）**: メイン画面はアイコン付きの一覧です。プレビューは横幅いっぱいに出て、下のつまみを引っ張ると大きさを変えられます。**右上の歯車アイコン** から **設定**（画面・接続・言語・アプリについて）が開きます。ライト／ダークは iPhone の設定に合わせて切り替わります。

> 言語は日本語と英語に対応しています（Windows は「設定 > 言語」、再起動で反映されます）。

## つながらないときは

- iPhone のロックを解除して、「このコンピュータを信頼」を押しましたか？
- iPhone で PhoneCam アプリを **前面に表示** していますか？（画面をロックするとカメラが止まります）
- [[よくある質問とトラブル]] を見てください。

## 安全のために

- USB でつなぐのが、いちばん安定して安全です。**Wi-Fi は初期状態でオフ**です。使うときは iPhone アプリ右上の歯車から **設定** を開き、「Wi-Fiからの接続を許可」をオンにして、画面に出る **6 桁のペアリングコード** を PC に入力します。
- 受信アプリの設定は `%APPDATA%\PhoneCam\phonecam_settings.json` に保存されます。

## アンインストール

受信アプリの左メニュー「映像」の「仮想カメラ」で **登録を解除** を押してから、exe と `%APPDATA%\PhoneCam` フォルダを削除します。
