# アップデート方法

新しいバージョンが出たら、**Windows の受信アプリ** と **iPhone のアプリ** の両方を更新します。変更内容は、[Releases](https://github.com/syuuga101/phonecam/releases) と [変更履歴](https://github.com/syuuga101/phonecam/blob/main/CHANGELOG.md) に書いてあります。

## Windows（受信アプリ）

受信アプリは、**アプリの中から自動で更新**できます。起動すると新しいバージョンを確認して、あると **「新しいバージョン vX.Y.Z があります」** と出ます。**今すぐ更新** を押すと、ダウンロードして入れ替え、アプリが再起動します（そのとき、接続中の映像はいったん切れます）。左メニュー「設定」の **更新を確認** からも確認できます。

自動で更新できないときは、手動でも更新できます。

1. [Releases](https://github.com/syuuga101/phonecam/releases/latest) から、最新の **PhoneCamReceiver.exe** をダウンロードします。
2. 受信アプリを終了して、古い exe を新しい exe に **置き換える** だけです（設定はそのまま引き継がれます）。

専用カメラの更新が必要なときは、画面の上に「仮想カメラ「PhoneCam」を新しい版に更新する必要があります」という帯が出ます（「更新する」を押すと管理者の確認が1回出ます）。帯を閉じたときは、左メニュー「映像」の「仮想カメラ」にある **登録する（更新）** を押してください（管理者の確認で「はい」）。

## iPhone（アプリ）

iPhone は、**SideStore で更新**します。PC は要りません。更新には 2 種類あります。

| 種類 | いつやる？ | 見出し |
|---|---|---|
| PhoneCam を **新しいバージョン** にする | 新しいバージョンが出たとき | 下の「PhoneCam を新しいバージョンにする」 |
| **7 日の期限** を延ばす | 週に 1 回（期限が切れる前） | 下の「7 日ごとの更新（期限を延ばす）」 |

どちらも、**LocalDevVPN を Connect にして、Wi-Fi につないでから**やります。

### 更新の前に（毎回の 3 点チェック）

1. □ iPhone の **LocalDevVPN** を開いて、**Connect** になっている（画面の上に VPN のマークが出ています）
2. □ iPhone が **Wi-Fi** につながっている（モバイル回線ではできません）
3. □ 別の VPN（WireGuard など）や、広告ブロックなどの DNS のアプリが **オフ** になっている

> 📷 画像: images/sidestore/11-localdevvpn-connected.png（LocalDevVPN が Connect 済みの画面と、画面上部の VPN マーク）

### PhoneCam を新しいバージョンにする

1. 上の「3 点チェック」をします。
2. **SideStore** を開きます。
3. 下のタブの **Sources** を開き、PhoneCam のソースを押します（または **My Apps** に、更新の表示が出ています）。
4. PhoneCam の **UPDATE**（更新）を押します。

> 📷 画像: images/sidestore/19-sidestore-update.png（SideStore で PhoneCam の「UPDATE」ボタンが出ている画面）

5. 待ちます。

**こうなればOK**: ホーム画面に戻り、数秒後に PhoneCam を開けて、バージョンが新しくなっている（PhoneCam の設定の「アプリについて」で確かめられます）。

更新が出ないときは、画面を下に引いて、更新を確認します。それでも出ないときは、次の「ソースを追加していないとき」を見てください。

**ソースを追加していないとき**（[[iPhoneアプリの入れ方（SideStore）]] の手順 7）:

```
https://github.com/syuuga101/phonecam/releases/latest/download/sidestore-source.json
```

SideStore の **Sources** の **＋** から、この URL を追加します。

### 7 日ごとの更新（期限を延ばす）

無料の Apple ID では、アプリは **7 日で期限が切れます**。期限が切れると、PhoneCam が開かなくなります。SideStore は、期限が近づくと、iPhone の中で自動で更新しようとします。ただし、確実ではないので、**週に 1 回は、自分で確かめて、更新する**のがおすすめです。

**手順**

1. 上の「3 点チェック」をします。
2. **SideStore** を開きます。
3. 下のタブの **My Apps** を開きます。
4. **SideStore** と **PhoneCam** の右に、**7 DAYS**（あと何日、という表示）が出ています。数字が小さくなっていたら、更新します。
5. **SideStore** の右の **7 DAYS** を押します（先に、SideStore を更新します）。
6. 「署名証明書を失効させるか、新しく作るか」という確認が出たら、**Yes**（または **Refresh Now**）を押します。
7. 終わったら、**PhoneCam** の右の **7 DAYS** を押します。

> 📷 画像: images/sidestore/13-sidestore-myapps.png（SideStore の My Apps。SideStore と PhoneCam の右に「7 DAYS」が出ている）

**こうなればOK**: 数字が **7 DAYS** に戻っている（押したあとは、ホーム画面に戻ることがあります）。

> **SideStore 自身**も 7 日で期限が切れます。SideStore が切れると、中のアプリを更新できなくなります。**必ず SideStore を先に更新してください。**
>
> 忘れないための工夫: iPhone のカレンダーかリマインダーに、「毎週 ○曜日に SideStore を開く」と登録しておくと確実です。

### 更新を忘れて、期限が切れたとき

PhoneCam が開かなくなったり、SideStore が開かなくなったりしたときです。落ち着いて、次の順に試してください。

**A. PhoneCam だけが切れた（SideStore は開く）**

1. 「3 点チェック」をします。
2. SideStore の **My Apps** を開きます。
3. PhoneCam の右の表示（期限切れを示す表示になっています）を押して、更新します。
4. 確認が出たら、**Yes**（または **Refresh Now**）を押します。

**こうなればOK**: PhoneCam が開けるようになる。

**B. SideStore も切れた（SideStore が開かない）**

SideStore が切れると、iPhone だけでは更新できません。**PC の iloader で、SideStore を入れ直します。**

1. iPhone を USB で PC につなぎます。iPhone のロックを解除して、「信頼」を押します。
2. PC で **iloader** を開き、手順 3 と同じ Apple ID でサインインします。
3. **Install SideStore (Stable)** を押します。
4. iPhone で LocalDevVPN を Connect にして、**SideStore** を開き、サインインします。
5. **My Apps** で、**SideStore の 7 DAYS を先に押して**、更新します（入れ直したあと、最初に更新しないと、あとで入れたアプリが消えることがあります）。
6. PhoneCam の期限も、同じように更新します。

詳しい画面は [[iPhoneアプリの入れ方（SideStore）]] の手順 3・6 を見てください。

**C. 更新のボタンを押すと、エラーになる**

[[よくある質問とトラブル]] の「更新できない」を、上から順に試します。「VPN に接続してください」と出るときは、LocalDevVPN の **Tunnel IP** を `10.7.0.0/32` にします。iOS を更新したあとなどは、**ペアリングファイル** の入れ直しが必要なことがあります（[[よくある質問とトラブル]] の「ペアリングファイルの期限切れ」）。

**D. どうしても直らない**

SideStore と、SideStore から入れたアプリをいったん消して、手順 3 から入れ直します（PhoneCam の設定は、iPhone の中に残らないことがあります）。

## バージョンをそろえましょう

PC と iPhone のバージョンが違っても、基本的には動きます（古いほうに合わせて動きます）。ただし、新しい機能（Wi-Fi のペアリングコードなど）は、両方を新しくしたときに使えます。

困ったときは [[よくある質問とトラブル]] へ。
