# アップデート方法

新しいバージョンが出たら、**Windows の受信アプリ** と **iPhone のアプリ** の両方を更新します。変更内容は、[Releases](https://github.com/syuuga101/phonecam/releases) と [変更履歴](https://github.com/syuuga101/phonecam/blob/main/CHANGELOG.md) に書いてあります。

## Windows（受信アプリ）

受信アプリは、**アプリの中から自動で更新**できます。起動すると新しいバージョンを確認して、あると **「新しいバージョン vX.Y.Z があります」** と出ます。**今すぐ更新** を押すと、ダウンロードして入れ替え、アプリが再起動します（そのとき、接続中の映像はいったん切れます）。左メニュー「設定」の **更新を確認** からも確認できます。

自動で更新できないときは、手動でも更新できます。

1. [Releases](https://github.com/syuuga101/phonecam/releases/latest) から、最新の **PhoneCamReceiver.exe** をダウンロードします。
2. 受信アプリを終了して、古い exe を新しい exe に **置き換える** だけです（設定はそのまま引き継がれます）。

専用カメラの更新が必要なときは、画面の上に「仮想カメラ「PhoneCam」を新しい版に更新する必要があります」という帯が出ます（「更新する」を押すと管理者の確認が1回出ます）。帯を閉じたときは、左メニュー「映像」の「仮想カメラ」にある **登録する（更新）** を押してください（管理者の確認で「はい」）。

## iPhone（アプリ）

SideStore には、PhoneCam を最新版にする **Update** と、アプリを使える期限を延ばす **Refresh** があります。無料の Apple ID では、SideStore と PhoneCam の両方を 7 日以内に更新します。

### 全体の流れ

| 状況 | 操作 | 目安 |
| --- | --- | --- |
| 新しい PhoneCam が出た | PhoneCam の **Update** を押します | 3〜5 分 |
| 期限が近づいた | **My Apps** で各アプリの残り日数を押します | 2〜5 分 |
| 期限を過ぎた | 開けるアプリに応じて、iPhone または PC から上書きします | 5〜15 分 |

### 用意するもの

- [ ] iPhone を Wi-Fi につなぎます。
- [ ] LocalDevVPN を開いて **Connect** を押します。
- [ ] 別の VPN を使用中の場合は切断します。
- [ ] SideStore が期限切れの場合は、iloader が入った Windows PC、データ通信対応 USB ケーブル、初回と同じ Apple ID を用意します。

> 📷 画像: images/sidestore/11-localdevvpn-connected.png（LocalDevVPN の接続済み画面）

**こうなれば OK**　iPhone が Wi-Fi につながり、LocalDevVPN が接続済みです。

### PhoneCam を新しいバージョンにする

1. SideStore を開きます。
2. **My Apps** を開きます。
3. PhoneCam の **Update** を押します。
4. 更新が完了したら、ホーム画面から PhoneCam を開きます。

> 📷 画像: images/sidestore/19-sidestore-update.png（PhoneCam の更新ボタン）

**こうなれば OK**　PhoneCam の設定にある「アプリについて」で、新しいバージョンを確認できます。

<details>
<summary>更新が出ないとき</summary>

PhoneCam の配布元を追加しているか、SideStore の **Sources** で確認します。追加の操作は [[iPhoneアプリの入れ方（SideStore）]] の手順 7 にあります。IPA（iPhone アプリのインストールファイル）を直接入れた場合は、最新版の IPA をダウンロードして、**My Apps** の **＋** から選びます。

</details>

### 7 日ごとの更新（期限を延ばす）

1. SideStore を開きます。
2. **My Apps** を開きます。
3. SideStore の右にある残り日数を押します。
4. ホーム画面に戻った場合は、更新が終わってから SideStore を開き直します。
5. **My Apps** で PhoneCam の右にある残り日数を押します。

> 📷 画像: images/sidestore/20-refresh-both.png（My Apps の SideStore と PhoneCam の残り日数）

**こうなれば OK**　両方の表示が **7 DAYS** に戻り、PhoneCam が開きます。

<details>
<summary>更新で Wi-Fi や VPN のエラーが出るとき</summary>

Wi-Fi と LocalDevVPN の両方が接続済みか確認します。接続済みでもエラーが続くときは、[[よくある質問とトラブル]] の LocalDevVPN の項目に沿って Tunnel IP を確認します。

</details>

### 更新を忘れて、期限が切れたとき

**PhoneCam だけが開かない場合**

1. SideStore を開きます。
2. **Sources** から PhoneCam の配布元を開きます。
3. PhoneCam を上書きで入れます。IPA から入れた場合は、**My Apps** の **＋** から、同じ版か新しい版の PhoneCam の IPA を選びます。
4. PhoneCam を開きます。

**こうなれば OK**　PhoneCam が開き、設定と映像を確認できます。上書きできるか確認する間は、iPhone に入っている PhoneCam を残しておきます。[SideStore 公式 FAQ](https://docs.sidestore.io/docs/faq)

**SideStore も開かない場合**

1. [[iPhoneアプリの入れ方（SideStore）]] の手順 1〜3 に沿って、同じ Apple ID で iloader から SideStore を上書きします。
2. 開くときに信頼やデベロッパモードを求められた場合は、導入ガイドの手順 4 を確認します。
3. 導入ガイドの手順 5〜6 に沿って、SideStore を開き、最初の更新を行います。
4. PhoneCam も期限切れなら、上の「PhoneCam だけが開かない場合」に沿って復旧します。

**こうなれば OK**　SideStore と PhoneCam の両方が開きます。

<details>
<summary>上書きや最初の更新ができないとき</summary>

[[よくある質問とトラブル]] の「ペアリングファイルの期限切れ」を確認してください。アプリを削除してから入れ直すと、アプリ内の設定やデータが消えることがあります。

</details>

## バージョンをそろえましょう

PC と iPhone のバージョンが違っても、基本的には動きます（古いほうに合わせて動きます）。ただし、新しい機能（Wi-Fi のペアリングコードなど）は、両方を新しくしたときに使えます。

困ったときは [[よくある質問とトラブル]] へ。
