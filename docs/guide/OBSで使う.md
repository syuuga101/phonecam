# OBSで使う

## 手順

1. iPhone で PhoneCam を開き、USB でつなぎます。
2. 受信アプリで接続し、映像が流れている（受信 fps が表示される）ことを確認します。
3. OBS で **ソース追加 > 映像キャプチャデバイス** を作ります。
4. デバイスに **PhoneCam** を選びます。

## ポイント

- 専用カメラの「PhoneCam」は OBS の仮想カメラとは別物なので、**OBS の「仮想カメラ開始」と同時に使えます**。
- 出力先は受信アプリの「接続・映像 > 出力先」で選べます。通常は **PhoneCam（専用カメラ）** のままで大丈夫です。
- 「OBS Virtual Camera」「Unity Capture」を選ぶと従来の仮想カメラで出力します（OBS の「仮想カメラ開始」とは同時に使えません）。

## おすすめ設定

- 映像キャプチャデバイスのプロパティで **「表示されていないときは非アクティブにする」** をオンにすると、そのシーンを表示している間だけカメラが動きます（発熱とバッテリーの節約になります）。
- ソースのバッファリングを無効にすると、遅延が減ることがあります。
- 縦長の映像にしたいときは、受信アプリの「映像 > 向き」を **縦** にして、OBS のキャンバスも縦にします。
- 4K で送っても、PhoneCam の出力は 1920×1080 のままです（PC の負荷を抑えるため）。4K で出したいときは、「出力サイズ（仮想カメラ）」も 4K にします。

## 背景を透明にする（緑の切り抜き）

受信アプリの「エフェクト」タブで背景を **切り抜き(緑)** にし、OBS のソースに **クロマキー** フィルタ（キーの色: 緑）を追加すると、背景が透明になります。

## 映像が出ないとき

- 受信アプリで接続して、映像が流れていますか？
- OBS のソースを開き直してください（プロパティを開いて OK）。
- 受信アプリで **出力サイズ・出力の形・向き** を変えたときだけ、OBS はソースを一度「非表示→表示」にしてください。
- それでもだめなときは [よくある質問とトラブル](%E3%82%88%E3%81%8F%E3%81%82%E3%82%8B%E8%B3%AA%E5%95%8F%E3%81%A8%E3%83%88%E3%83%A9%E3%83%96%E3%83%AB.md) へ。
