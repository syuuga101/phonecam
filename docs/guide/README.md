# PhoneCam 使い方ガイド

使っていない iPhone を、Windows 用の低遅延ウェブカメラ＆マイクにするアプリ **PhoneCam** の使い方ガイドです。

> **ご利用にあたって**: PhoneCam は、ご自分のカメラ・マイクを配信やビデオ通話で使うためのアプリです。他の人を同意なく撮影・録音することや、盗撮など法律に反する目的で使うことは禁止です。人を撮影・録音・配信するときは、相手の同意をとってください。詳しくは [トップページ](https://github.com/syuuga101/phonecam#%E3%81%94%E5%88%A9%E7%94%A8%E3%81%AB%E3%81%82%E3%81%9F%E3%81%A3%E3%81%A6) へ。

## はじめての方

1. [はじめに（セットアップ）](%E3%81%AF%E3%81%98%E3%82%81%E3%81%AB%EF%BC%88%E3%82%BB%E3%83%83%E3%83%88%E3%82%A2%E3%83%83%E3%83%97%EF%BC%89.md): ダウンロードから、OBS / Discord に「PhoneCam」が出るまで
2. [iPhoneアプリの入れ方（AltStore）](iPhone%E3%82%A2%E3%83%97%E3%83%AA%E3%81%AE%E5%85%A5%E3%82%8C%E6%96%B9%EF%BC%88AltStore%EF%BC%89.md): iPhone にアプリを入れる手順
3. [OBSで使う](OBS%E3%81%A7%E4%BD%BF%E3%81%86.md) / [Discordで使う](Discord%E3%81%A7%E4%BD%BF%E3%81%86.md)

## 便利な使い方

- [音声（iPhoneのマイク）を使う](%E9%9F%B3%E5%A3%B0%EF%BC%88iPhone%E3%81%AE%E3%83%9E%E3%82%A4%E3%82%AF%EF%BC%89%E3%82%92%E4%BD%BF%E3%81%86.md): iPhone のマイクを OBS・Discord のマイクにする
- [画質と遅延の調整](%E7%94%BB%E8%B3%AA%E3%81%A8%E9%81%85%E5%BB%B6%E3%81%AE%E8%AA%BF%E6%95%B4.md): おすすめ設定、遅延を小さくするコツ
- [録画機能](%E9%8C%B2%E7%94%BB%E6%A9%9F%E8%83%BD.md): iPhone の中で高画質に録画する
- [ショートカットキー](%E3%82%B7%E3%83%A7%E3%83%BC%E3%83%88%E3%82%AB%E3%83%83%E3%83%88%E3%82%AD%E3%83%BC.md): OBS やゲーム中でも、キーボードでカメラ切り替え・ミュート・録画など

## 必要なもの

- iPhone（iOS 17 以上）
- Windows 10 / 11 の PC
- USB ケーブル
- Apple ID（無料でOK）

最新版は [Releases](https://github.com/syuuga101/phonecam/releases/latest) からダウンロードできます。
