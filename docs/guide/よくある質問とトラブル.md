# よくある質問とトラブル

症状から探してください。解決しないときは、受信アプリの **「状態」タブ** の内容を添えて [Issues](https://github.com/syuuga101/phonecam/issues) へ。

## 接続できない

| 症状 | 対処 |
|---|---|
| 「Apple Mobile Device Service に接続できません」 | iTunes（Apple 公式サイト版）、または Microsoft Store の「Apple Devices」アプリを入れて、PC を再起動します。 |
| 「iPhoneがUSBで見つかりません」 | ケーブルを確認し、iPhone のロックを解除して「このコンピュータを信頼」を押します。 |
| 「iPhoneのPhoneCamアプリに接続できません」 | iPhone で PhoneCam を起動し、**前面に表示したまま**にします。 |
| Wi-Fi で接続できない | Wi-Fi は初期状態でオフです。iPhone アプリで「Wi-Fiからの接続を許可」をオンにしてください。iPhone と PC が同じネットワークか確認し、初回のローカルネットワークの許可も必要です。 |
| 「ペアリングコードが違います」 | iPhone の画面に表示されている 6 桁のコードを入力してください（「コードを変更」で変えた場合は新しいコード）。同じ PC から 3 回続けて間違えると、60 秒は受け付けません。 |
| 画面が消えて止まる | iPhone をロックするとカメラが止まります。アプリを前面に表示したままにしてください。 |

## iPhone にアプリが入らない

### AltServer.ServerError 2005 と出る

AltStore の「My Apps」で、AltStore を一度 **Refresh** してから、もう一度インストールします。

### 「requires additional permissions not specified by the source」と出る

PhoneCam v1.3.5 以降で直っています。AltStore のソースを入れ直して、最新版を入手してください。

### 数日後にアプリが開かなくなった

無料の Apple ID は **7 日で期限切れ**になります。PC で AltServer を動かして同じ Wi-Fi につなぎ、AltStore の「My Apps」で更新（Refresh）してください（Sideloadly で入れた場合は再インストール）。

詳しくは [iPhoneアプリの入れ方（AltStore）](iPhone%E3%82%A2%E3%83%97%E3%83%AA%E3%81%AE%E5%85%A5%E3%82%8C%E6%96%B9%EF%BC%88AltStore%EF%BC%89.md)。

## カメラが出ない・映像が出ない

| 症状 | 対処 |
|---|---|
| 「PhoneCam」がカメラ一覧に出ない／「未登録」と出る | 受信アプリを起動してください。「接続・映像」タブの「PhoneCamカメラ」の **登録する（更新）** を押します（管理者の確認で「はい」）。 |
| OBS で映像が出ない | 受信アプリで接続して映像が流れている必要があります。OBS のソースを開き直してください。 |
| Discord が黒い／カメラが動き始めない | 受信アプリを先に起動してから、Discord でカメラを選びます。サイズなどを変えたあとは、カメラを一度オフ→オン。「状態」タブの「使用中の検出」が「未使用」ならカメラを選び直し、「共有メモリなし」ならカメラの登録と出力先を確認します。 |
| OBS Virtual Camera を開始できない | OBS Studio 30 以上を入れて、OBS 側の「仮想カメラ開始」がオンなら止めてください。 |
| 4K にすると映像が出ない／重い | 4K で送っても、仮想カメラは「出力サイズ」（既定 1920×1080）のままなのでそのまま使えます。CPU 負荷が高いときは「ハードウェアデコード」をオンにします（既定でオン）。 |

## 映像の品質

| 症状 | 対処 |
|---|---|
| 映像が固まる／乱れる | 自動でキーフレームを再要求します。直らないときは、ビットレートを下げるか、USB を使います。Wi-Fi のときは HEVC も試してください。 |
| 映像が暗い／ちらつく | 露出をマニュアルにして、シャッター速度を地域に合わせます（[画質と遅延の調整](%E7%94%BB%E8%B3%AA%E3%81%A8%E9%81%85%E5%BB%B6%E3%81%AE%E8%AA%BF%E6%95%B4.md)）。 |

## 「PCの処理が追いつかないためフレームを間引いています」と出る（コマ落ち）

PC のデコードが映像に追いついていません。遅れを溜めないために、次のキーフレームまで映像を間引いています。次のことを試してください。

- **ハードウェアデコード** をオンにする（接続・映像タブ）
- 出力サイズ（1080p など）を小さくする
- fps を下げる
- 4K で送っているなら 1080p にする

## 音声のトラブル

### VB-CABLE を入れたら PC の音が出なくなった

VB-CABLE のインストーラーが、Windows の「既定の音の出力先」を **CABLE** に切り替えてしまうことがあります。PhoneCam は自動で元に戻しますが（入れたあとの約 20 秒間と、次の 2 回の起動時）、戻らなかったときは、タスクバーのスピーカーのアイコンから出力先を元のスピーカー／ヘッドホンに選び直してください。

### iPhone のマイクの音が出ない・遅れる・途切れる

[音声（iPhoneのマイク）を使う](%E9%9F%B3%E5%A3%B0%EF%BC%88iPhone%E3%81%AE%E3%83%9E%E3%82%A4%E3%82%AF%EF%BC%89%E3%82%92%E4%BD%BF%E3%81%86.md) を見てください。

## アプリの動作

### 自動起動しない（カメラが使われても動き始めない）

カメラは初期設定の「**使われているときだけ（自動）**」のとき、OBS や Discord が PhoneCam を開いたときに動き始めます（判定に最大 3 秒、起動に 1〜2 秒）。

- 自動判定は、出力先が **PhoneCam（専用カメラ）** のときだけ使えます。
- 受信アプリを先に起動してください。
- 「状態」タブの「使用中の検出」を確認してください。
- 自動のとき、**一時停止** を押すと止まります。OBS や Discord がカメラを開き直すか、**開始** を押すと再開します。
- 常に動かしたいときは、「接続中ずっと」にします。

### 画面の文字や行が切れる（高DPI）

受信アプリは高 DPI に対応しています。ウィザードは大きさを変えられ、中身はスクロールできます。それでも切れるときは、ウィンドウを広げてください。

## 質問

**Q. Mac は必要ですか？** いいえ。iPhone アプリも GitHub Actions で作っていて、AltStore で入れます。

**Q. Wi-Fi でも使えますか？** 使えます。ただし初期状態ではオフで、使うときは iPhone アプリで許可して、6 桁のペアリングコードを入力します。Wi-Fi の通信は暗号化されないので、信頼できるネットワークだけで使ってください。USB のほうが安定していて、遅延も小さいです。

**Q. 設定はどこに保存されますか？** `%APPDATA%\PhoneCam\phonecam_settings.json` です。

## それでも解決しないとき

[Issues](https://github.com/syuuga101/phonecam/issues) の「不具合の報告」から、環境（Windows / iPhone / PhoneCam のバージョン / USB か Wi-Fi か）と、「状態」タブの内容を書いて送ってください。
