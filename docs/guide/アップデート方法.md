# アップデート方法

新しいバージョンが出たら、**Windows の受信アプリ** と **iPhone のアプリ** の両方を更新します。変更内容は、[Releases](https://github.com/syuuga101/phonecam/releases) と [変更履歴](https://github.com/syuuga101/phonecam/blob/main/CHANGELOG.md) に書いてあります。

## Windows（受信アプリ）

1. [Releases](https://github.com/syuuga101/phonecam/releases/latest) から、最新の **PhoneCamReceiver.exe** をダウンロードします。
2. 受信アプリを終了して、古い exe を新しい exe に **置き換える** だけです（設定はそのまま引き継がれます）。
3. 専用カメラの更新が必要なときは、起動時に案内が出ます。「接続・映像」タブの **登録する（更新）** を押してください（管理者の確認で「はい」）。

## iPhone（アプリ）

### AltStore のソースから入れた場合（おすすめ）

1. iPhone で AltStore を開きます。
2. **My Apps**（または Updates）に PhoneCam の更新が出ていたら、**Update** を押します。
3. 出ないときは、PC の AltServer を起動して同じ Wi-Fi につなぎ、AltStore の画面を下に引いて更新（Refresh）します。

ソースの URL（追加していないとき）:

```
https://github.com/syuuga101/phonecam/releases/latest/download/altstore-source.json
```

### AltServer や Sideloadly で直接入れた場合

新しい `PhoneCam.ipa`（Releases の添付ファイル）を、もう一度同じ方法で入れ直します。

## バージョンをそろえましょう

PC と iPhone のバージョンが違っても、基本的には動きます（古いほうに合わせて動きます）。ただし、新しい機能（Wi-Fi のペアリングコードなど）は、両方を新しくしたときに使えます。

## 7 日の期限

無料の Apple ID では、アプリは 7 日で期限が切れます。PC で AltServer が動いていて、同じ Wi-Fi につながっている間は、AltStore が自動で更新します。

困ったときは [よくある質問とトラブル](%E3%82%88%E3%81%8F%E3%81%82%E3%82%8B%E8%B3%AA%E5%95%8F%E3%81%A8%E3%83%88%E3%83%A9%E3%83%96%E3%83%AB.md) へ。
