# ショートカットキー

OBS やゲームの画面を操作しているときでも、キーボードで PhoneCam を操作できます（v1.5.0 以降）。受信アプリを前に出す必要はありません。

## 初期設定のキー

| 操作 | キー |
|---|---|
| カメラ切り替え（広角 → 超広角 → インカメ → …） | Ctrl + Alt + C |
| マイクのミュート 切り替え | Ctrl + Alt + M |
| 背景ぼかし オン / オフ | Ctrl + Alt + B |
| カメラの開始 / 一時停止 | Ctrl + Alt + P |
| 録画の開始 / 停止 | Ctrl + Alt + R |
| ズームを上げる（0.25 ずつ） | Ctrl + Alt + ↑ |
| ズームを下げる（0.25 ずつ） | Ctrl + Alt + ↓ |

キーを押すと、受信アプリの画面の下に「マイク: ミュート」のような短いお知らせが出ます。

- カメラ切り替えは、その iPhone で使えるレンズだけを順番に切り替えます。
- 録画とカメラの開始 / 一時停止は、iPhone につながっているときだけ動きます。

## キーを変える

1. 受信アプリの **ショートカット** タブを開きます。
2. 変えたい操作の **変更** を押します。
3. 使いたいキーを押します。**Ctrl・Alt・Shift・Win のどれか** と、文字・数字・F1〜F12・矢印・PageUp/PageDown・Home/End・Space のどれかを一緒に押します。
4. やめるときは Esc を押します。

**なし** を押すと、その操作のショートカットを使わなくなります。**すべて初期設定に戻す** で元に戻せます。設定は保存されます。

## ショートカットを全部オフにする

「ショートカットキーを使う」のチェックを外します。ほかのアプリのキー操作とぶつかるときや、使いたくないときに便利です。

## 「このキーは他のアプリが使っています」と出たとき

そのキーの組み合わせを、ほかのアプリがすでに使っています。**変更** から別のキーを選んでください。Ctrl + Alt + 文字 のキーを使うアプリは多いので、Shift を足すとぶつかりにくくなります。
