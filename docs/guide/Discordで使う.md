# Discordで使う

## 手順

1. **受信アプリを先に起動**して、iPhone とつなぎます。
2. Discord の **ユーザー設定 > 音声・ビデオ** を開きます。
3. **カメラ** に **PhoneCam** を選びます。
4. 通話で「カメラをオン」にします。プレビューに映像が出ます。

## ポイント

- PhoneCam の専用カメラは、受信アプリを開いている間は用意されています。カメラが止まっていても Discord のカメラ一覧に「PhoneCam」が出て、選ぶとカメラが動き始めます（起動に 1〜2 秒かかります）。
- 初期設定の「**使われているときだけ（自動）**」のときは、カメラをオンにすると iPhone のカメラが動き始め、オフにすると止まります。
- マイクに iPhone を使うときは、Discord のマイクに **CABLE Output** を選びます（[音声（iPhoneのマイク）を使う](%E9%9F%B3%E5%A3%B0%EF%BC%88iPhone%E3%81%AE%E3%83%9E%E3%82%A4%E3%82%AF%EF%BC%89%E3%82%92%E4%BD%BF%E3%81%86.md)）。

## 映像が出ない・黒いとき

- 受信アプリを先に起動してから、Discord でカメラを選んでください。
- 受信アプリの出力サイズ・出力の形・向きを変えたあとは、Discord のカメラを **一度オフ→オン** にします。
- 受信アプリの「状態」タブにある「使用中の検出」を見てください。
  - **未使用** のまま: Discord 側でカメラを選び直してください。
  - **共有メモリなし**: PhoneCam カメラの登録（「接続・映像」タブの **登録する（更新）**）と、出力先が「PhoneCam（専用カメラ）」になっているかを確認してください。
