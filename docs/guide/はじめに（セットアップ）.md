# はじめに（セットアップ）

PC に受信アプリを入れて、OBS や Discord でカメラが使えるようになるまでの手順です。所要時間は 15〜30 分ほどです。

## 用意するもの

- iPhone（iOS 17 以上）と USB ケーブル
- Windows 10 / 11 の PC
- Apple ID（無料のものでOK。サブのアカウントでも構いません）

## 手順

### 1. 受信アプリをダウンロード

[Releases](https://github.com/syuuga101/phonecam/releases/latest) から **PhoneCamReceiver.exe** をダウンロードします（ファイルはこの 1 つだけです）。置き場所はどこでも構いません。

### 2. 起動してセットアップウィザードに従う

`PhoneCamReceiver.exe` をダブルクリックします。

> Windows の青い警告（SmartScreen）が出たら、**詳細情報 → 実行** を選びます。PhoneCam の exe にはまだ署名がついていないためです。

初回は **セットアップウィザード** が開きます。**次へ** を押して進めます。

1. **ようこそ**: 内容の説明です。
2. **必要なソフトの確認**: 入っているものは自動で「スキップ」になり、足りないものだけにチェックが付きます。**インストール** を押します。
3. **インストール**: 次の 2 通りで進みます。
   - **自動で入れるもの**（Visual C++ ランタイム、PhoneCam カメラの登録）: 管理者の確認（UAC）が **1回** 出るので **「はい」** を押します。
   - **手順つきで入れるもの**（iTunes・iCloud・AltServer・VB-CABLE）: ダウンロードと確認のあと、画面に押すボタンの手順が出ます。**インストーラーを開く** を押すと、公式のインストーラーが普通のウィンドウで開きます。案内どおりに進め、終わったら **確認** を押します。見つからないときは何が足りないかが表示され、**公式ページを開く** から自分で入れることもできます。インストーラーの画面が見えないときは、ほかのウィンドウの後ろやタスクバーを確認してください。
4. **iPhoneの準備**: iPhone にアプリを入れる 7 ステップを案内します。詳しくは [iPhoneアプリの入れ方（AltStore）](iPhone%E3%82%A2%E3%83%97%E3%83%AA%E3%81%AE%E5%85%A5%E3%82%8C%E6%96%B9%EF%BC%88AltStore%EF%BC%89.md)。

ウィザードが入れるもの（足りないものだけ）:

| ソフト | 用途 | 必要か |
|---|---|---|
| PhoneCamカメラ | OBS や Discord に出る専用カメラ | 必須 |
| Visual C++ ランタイム | 専用カメラの動作に必要 | 必須 |
| Apple USBドライバ（iTunes） | USB 接続に必要 | USB で使うなら必須 |
| iCloud（Apple 公式サイト版） | AltServer の動作に必要 | 任意 |
| AltServer | iPhone へアプリを入れて、自動で更新する | おすすめ |
| VB-CABLE | iPhone のマイクを OBS などで使う | 任意（[音声（iPhoneのマイク）を使う](%E9%9F%B3%E5%A3%B0%EF%BC%88iPhone%E3%81%AE%E3%83%9E%E3%82%A4%E3%82%AF%EF%BC%89%E3%82%92%E4%BD%BF%E3%81%86.md)） |

- iTunes・iCloud・VB-CABLE などを入れたあと、**PC の再起動が必要**になることがあります。インストーラーに「再起動」と出たら「あとで」を選び、セットアップがすべて終わってから再起動してください。
- 自動で入れられなかったものは、公式ページを開いて手順を案内します。エラーの表示には、次にやることが 1 行で書いてあります（技術的な内容は「詳細」に出ます）。
- あとから「**セットアップ**」タブで、いつでも確認・インストールができます。

### 3. カメラを選ぶ

iPhone で PhoneCam アプリを開き、USB でつないだまま、受信アプリで接続します。映像が流れたら、OBS や Discord のカメラで **「PhoneCam」** を選びます。

- [OBSで使う](OBS%E3%81%A7%E4%BD%BF%E3%81%86.md)
- [Discordで使う](Discord%E3%81%A7%E4%BD%BF%E3%81%86.md)

## つながらないときは

- iPhone のロックを解除して、「このコンピュータを信頼」を押しましたか？
- iPhone で PhoneCam アプリを **前面に表示** していますか？（画面をロックするとカメラが止まります）
- [よくある質問とトラブル](%E3%82%88%E3%81%8F%E3%81%82%E3%82%8B%E8%B3%AA%E5%95%8F%E3%81%A8%E3%83%88%E3%83%A9%E3%83%96%E3%83%AB.md) を見てください。

## 安全のために

- USB でつなぐのが、いちばん安定して安全です。**Wi-Fi は初期状態でオフ**です。使うときは iPhone アプリで「Wi-Fiからの接続を許可」をオンにして、画面に出る **6 桁のペアリングコード** を PC に入力します。
- 受信アプリの設定は `%APPDATA%\PhoneCam\phonecam_settings.json` に保存されます。

## アンインストール

受信アプリの「接続・映像」タブで **登録を解除** を押してから、exe と `%APPDATA%\PhoneCam` フォルダを削除します。
