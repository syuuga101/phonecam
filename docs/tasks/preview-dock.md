# タスク: 設定ページでプレビューを見ながら調整できるようにする（プレビュードック）

## 目的（ユーザーの要望）
「プレビューを見ながら広角とか操作したいから、映像や音声はプレビューを見ながらいじれるようにしたい」
今はプレビューがカメラページにしか無く、映像ページの「レンズ・出力」などを変えても結果が見えない。

## 仕様（Opus 決定・変えない）
1. 対象ページ: 映像・画質・エフェクト・音声。カメラページはそのまま。
2. 配置
   - ウィンドウ幅（論理 px）1100 以上: ページ右に固定幅約 380px・16:9 の列。上端固定、左の設定欄だけスクロール。
   - それ未満: ページ上部に固定の帯（高さ約 200px、16:9 中央）、その下の設定欄がスクロール。
   - ページ見出しの右に小さなトグル「プレビュー」。出す/隠すの状態は設定に保存（全ページ共通 1 つ）。
3. 描画
   - 受信・デコードを増やさない。カメラページのプレビューと同じ発生源のフレームを描くだけ。
   - 既存の「プレビュー fps」設定に従う。
   - 見えていないとき（非表示・別ページ・最小化）は描画しない。
   - 未接続時はカメラページと同じ「未接続」表示。
4. 情報
   - 映像左下に小さな半透明ラベルで現在値「広角 · 1080p · 60fps」。compact.sum の作り方を流用する。
   - 音声ページはプレビューの下に入力レベルメーター（既存流用）とミュート状態。
5. 複数カメラ: 各ページのカメラ選択に合わせて、ドックも同じカメラを表示する。
6. デザイン
   - 既存の配色関数（card_color / border_color など）と既存の角丸を使い、Apple 風に控えめに。
   - 水色背景・大きな角丸は使わない。
   - ライト/ダーク、拡大率 100〜200% で崩れないこと。
7. 文言は ja.json / en.json 両方に足し、キー数を揃える（tests/test_i18n.py が通ること）。
8. テスト
   - ドックの表示切り替え、広い/狭いでの配置切り替え、非表示時に描画しないことを Qt テストで確認する。
   - qt_smoke で、映像ページ（「レンズ・出力」を開いた状態）と音声ページを、広い/狭い両方で撮る。

## 守ること
