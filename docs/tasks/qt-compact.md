# タスク: Qt 画面を「たたんで情報を減らす」Windows 11 設定風 UI にする（Codex向け）

## 目的
いまの各ページは、すべての項目と説明文が常に開いて並んでいて情報量が多すぎる。
Windows 11 の「設定」アプリ（タスクマネージャーの設定ページなど）のように、
**よく使うものだけを最初に見せ、細かい項目は折りたたみ（エキスパンダー）にしまう**。
オン/オフはチェックマーク・スイッチで一目で分かるようにし、説明文は短くする。

参考（ユーザー提示）: Windows 11 タスクマネージャー設定の「その他のオプション」。
- 閉じた状態: 左にアイコン、太字の見出し、その下に中身の要約（グレー小さめ）、右端に ∨。
- 開いた状態: 同じカードの下に、少し暗い背景で子項目が1行ずつ（チェックボックス＋ラベル）並び、右端は ∧。
- カードは角丸・薄い枠、行の間は細い区切り線。

## 対象
`windows/phonecam/qt/`（widgets.py と pages/*.py、9 ページ）。ロジックは `controller.py` を使い、挙動は変えない。

## やること
1. `widgets.py` に `Expander`（折りたたみカード）を追加する。
   - アイコン・見出し・要約・右側のコントロール（任意。例: スイッチ）を持てる。
   - クリックで開閉し、小さなアニメーションをつける。
   - 開閉状態をページごとに設定へ保存する（キー例 `ui_expanded`、dict）。
   - ライト/ダーク、拡大率 100%〜200% で崩れないこと。既存の配色関数（`card_color`、`border_color` など）を使う。
2. 全 9 ページを見直す。
   - 各ページで最初に見えるのは「主要な操作 2〜4 個」だけにする。詳細設定・上級者向け・トラブル対策は Expander に入れる。
   - 説明文（Hint）は 1 行程度に短くし、長い説明は Expander の中か、ツールチップ（ⓘ）に移す。
   - オン/オフはスイッチかチェックで表し、状態が見て分かるようにする（例: 「接続中 ✓」「未導入」のように、状態をアイコンと色で示す）。
   - 例: 映像ページは「解像度・fps・向き」を表に出し、レンズ・出力の形・合わせ方などを「詳細」にしまう。設定ページは「テーマ・言語・更新」を表に出し、その他をしまう。
3. 文言を足したり変えたりしたら、`windows/locales/ja.json` と `en.json` の両方を更新する。キーの数を揃える。
4. `windows/qt_smoke.py` が全ページで動くことを確認する。Expander を開いた状態のスクショも、各ページ 1 枚ずつ追加する。

## 守ること
- 機能を消さない。すべての設定に今までどおりたどり着けること。
- Tk 版（`phonecam/ui/`）とセットアップウィザードは触らない。
- 始める前に `git merge origin/main` で最新を取り込む（v2.1.1 で、スライダー・バージョン表示・プレビュー fps 設定が入っている）。
