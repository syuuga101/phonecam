# タスク: Windows の権限境界・配布検証・CI の強化（監査 #5、#6、#11〜#16）

監査報告: `docs/audit/2026-11-15-audit.md`。各指摘はまずコードで事実を確かめる。#16 の CVE 番号は Qt 公式の一覧と照合し、実在しない番号なら PR に書く。

## やること
- **#5** 管理者ヘルパー: `job.json` は 1 回だけ読み、そのバイト列でハッシュの照合と JSON の解釈を両方行う。実行できる手順・引数・出力先は、ヘルパー側の許可リストで固定する。
- **#6** `--unregister`: レジストリの値は `HKLM\SOFTWARE\Classes` から明示的に読む。DLL のパスがアプリの管理下にあることと、ハッシュが正しいことを確かめてから解除する。
- **#11** 共有メモリとミューテックス: NULL DACL をやめ、今のユーザーだけに権限を与える DACL にする。Python 側と DLL 側の両方を直す。受け取る制御メッセージの値の範囲も検証する。
- **#12** 更新: ハッシュが無い場合は更新を中止する。更新マニフェスト（バージョン・SHA-256）に署名する仕組みを提案し、作れる範囲で実装する。例: Ed25519 の公開鍵を exe に埋め込み、秘密鍵は GitHub Secrets に置く。秘密鍵の作り方と登録の手順は、PR に書いてユーザーに任せる。
- **#13** VB-CABLE と iloader: パッケージ全体を固定ハッシュで照合する。署名を検証するときは失効も確認するよう明示する。
- **#14** 仮想カメラの登録: DLL をコピーした後に内容を照合し直す。32 ビットと 64 ビットの結果を別々に返し、片方だけ失敗したときは UI に表示する。
- **#15** CI:
  - Actions を SHA で固定する。
  - softcam の取得を SHA で固定する。
  - pip はハッシュ付きでロックする。
  - XcodeGen の版を固定する。
  - `VERSION` は形式（`^\d+\.\d+\.\d+$`）を検証し、環境変数で渡す。
- **#16** Qt を修正済みの版に更新する。更新後にビルド、起動テスト、スクショがすべて通ること。

## 守ること
- 動作・UI は変えない。ただし #14 の失敗表示は追加する。
- USB 接続まわり（`link.py`、`usbmux.py`）は触らない。暗号化は別の PR（`codex/secure-link`）で扱う。
- CI（pytest / build / qt-screenshots / Build iOS）がすべて成功すること。
- 確かめたこと・確かめていないことを、PR に日本語で書く。
