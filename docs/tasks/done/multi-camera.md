# タスク: PC 1台に iPhone を複数台つなぎ、OBS に別々のカメラとして出す（Codex向け）

## ゴール
2台目以降の iPhone（または iPad）も同時につなぎ、Windows に「PhoneCam カメラ」「PhoneCam カメラ 2」…として別々の仮想カメラを出す。
OBS ではそれぞれを別のソースとして選べるようにする。1台の iPhone で前後のカメラを同時に使う機能は対象外。

## 現状
- 受信は 1 台前提。windows/phonecam/core/link.py、stream.py、vcam.py、controller.py。
- 仮想カメラ（softcam）は 1 つ。CLSID は .github/workflows/windows.yml で DLL にパッチして埋め込み、windows/phonecam/core/softcam_reg.py で登録している。共有メモリ名とカメラ名も 1 つ。
- 設定も 1 台分（`%APPDATA%\PhoneCam\phonecam_settings.json`）。

## やること
1. **仮想カメラを複数にする**
   - 最大 4 台。CLSID・カメラ名（「PhoneCam カメラ 2」など）・共有メモリ名が別々の softcam を登録できるようにする。
   - 方法は、CI で CLSID を変えた DLL を台数分作る、または 1 つの DLL で複数フィルタを登録できるようにする。どちらか実現できる方を選び、理由を PR に書く。
   - 登録・解除は既存の管理者ヘルパー（`--register` / `--unregister` / `--setup <job>`）と、初期セットアップの「PhoneCamカメラ」の手順に組み込む。2台目以降は、使うときに追加登録する形でよい。
2. **受信を複数台にする**
   - 接続（Link）・デコード・出力を端末ごとに持つ。端末ごとに、どの仮想カメラ番号に出すかを持つ。
   - 自動起動・自動停止（使用中の検出）は、仮想カメラごとに判定する。
3. **設定を分ける**
   - 端末ごとの設定（映像・画質・エフェクト・接続先）と、アプリ全体の設定（テーマ・言語・更新など）に分ける。
   - 今の設定ファイルからの移行処理を入れ、既存の設定は 1 台目に引き継ぐ。
4. **UI（Qt）**
   - 画面上部か左のナビに「カメラ 1 / カメラ 2 / ＋追加」の切り替えを置く。映像・画質・エフェクト・状態の各ページは、選んでいるカメラの設定を表示する。
   - 接続ページでは、端末ごとに接続状態と「出力先カメラ」を見せる。
5. **音声**
   - 音声（マイク）は、選んだ 1 台だけを使う（既定は 1 台目）。

## 守ること
- 1 台だけで使う人には、今と同じ見た目・同じ操作で使えること（カメラが 1 台なら切り替えは目立たせない）。
- iPhone アプリ側の変更は最小限にする（各 iPhone はそれぞれ今までどおりサーバとして待ち受ける）。
- 始める前に `git merge origin/main` で最新を取り込む（Wi-Fi ペアリングの PR が先に入っているはず。known_devices と整合させる）。

## 確認
- Windows で exe をビルドし、2 台の iPhone（なければ 1 台 + 片方は接続なしでも、仮想カメラが 2 つ見えるところまで）で確認する。
- OBS に 2 つのソースとして出ること、それぞれの設定が独立していること。
- 確認できたこと・できなかったことを PR の説明に日本語で書く。
