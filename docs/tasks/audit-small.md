# タスク: 監査の小さい修正（#7、#8、#10、#17、#18、#22）

監査報告: `docs/audit/2026-11-15-audit.md`。各指摘はまずコードで事実を確かめる。

## やること
- **#7** 受信のタイムアウト: `read_exact` がタイムアウトを無期限に再試行しないようにする。認証、受信開始、フレームの途中、それぞれに期限を設ける（例: 認証 10 秒、無通信 5 秒）。期限が来たら切断し、再接続か USB/Wi-Fi の切り替えに進む。usbmux でも同じようにする。
- **#8** 受信の上限: パケットの種別ごと・認証段階ごとに長さの上限を設ける。usbmux が宣言する長さにも上限を設ける。音声は、変換する前にサンプル数と変換後の見込みサイズを確かめる。
- **#10** 端末名・エラー・リリースノートを表示するラベルを `Qt.PlainText` にし、表示する長さを制限する。全ラベルを検索して、ネットワークや外部から来た文字列を表示している所をすべて直す。
- **#17** プレビュードックのマイク表示: iPhone 側のミュートと PC 側のミュート、マイクを使わない設定を区別して表示する。文言は ja と en の両方に入れる。
- **#18** iOS の録画: 完了コールバックに録画セッションの ID を渡す。古い録画の結果が、新しい録画のサイズやエラーの表示に混ざらないようにする。
- **#22** `get-task-allow`: SideStore で再署名すると上書きされるかを調べ、外しても問題なければ外す。分からなければ調べた結果だけを PR に書き、外さない。

## テスト
- #7・#8・#10・#17 は pytest でテストする。偽のソケットを使い、無応答、巨大な長さ、HTML の名前、ミュートの組み合わせを確かめる。
- #18 は `ios/Tests` で確かめられる範囲を確かめる。
- CI（pytest / build / qt-screenshots / Build iOS）がすべて成功すること。

## 守ること
- 接続の暗号化（別の PR `codex/secure-link`）と、Windows の権限まわり（別の PR `codex/win-hardening`）には手を出さない。
- USB を優先して接続する挙動を変えない。
